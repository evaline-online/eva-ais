## Methodology

Models are fetched live from public APIs and leaderboard endpoints:
- **Chatbot Arena (LMSYS)**: Live Elo-ranked leaderboard at `chat.lmsys.org/ranking.json`
- **HuggingFace Open LLM**: Popular open-weight models sorted by likes
- **OpenRouter**: Full model catalog via `openrouter.ai/api/v1/models`
- **Gemini API**: Official model list from `generativelanguage.googleapis.com`
- **Groq**: Developer API model list
- **Mistral AI**: Official model list via API
- **Cerebras**: Official model list via API
- **Cloudflare AI**: Workers AI model search endpoint

New models are identified by checking against the existing `models_catalog.json` from `scan_all_llms.py`.
